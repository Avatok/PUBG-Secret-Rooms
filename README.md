# 🔒 PUBG Secret Rooms – Alle Orte & Schlüsseltypen

Diese Website bietet eine vollständige Übersicht aller **Secret Room Locations** in **PUBG: Battlegrounds** – inklusive Informationen, **welcher Schlüssel** für welchen Raum benötigt wird.  
Die Seite ist einfach aufgebaut, schnell geladen und direkt über **GitHub Pages** erreichbar.

🌐 **Live Website:** https://avatok.github.io/PUBG-Secret-Rooms/

---

## 🗺️ Beschreibung

PUBG enthält auf verschiedenen Maps geheime Räume (“Secret Rooms”), die nur mit bestimmten **Keys** geöffnet werden können.  
Auf dieser Website findest du:

- 📍 **Alle bekannten Secret Room Standorte**
- 🗝️ **Den passenden Schlüsseltyp** für jeden Raum
- 🧭 **Einfache, schnelle Übersicht** – keine Installation, kein Login
